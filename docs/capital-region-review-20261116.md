# 수도권 업체 보강 후 AI 검토

2026-11-16. 사업장·공정 데이터는 server PR #47에서 관리한다. 이 변경은 같은 공개 근거를 검토할 때 **알루미늄캔을 다른 형태로 잘못 보류하던 오류**를 고친다.

고용24에 공개된 현대자원산업 화성 사업장 직무자료는 알루미늄캔의 수거·선별·가공을 설명한다. 모델이 이 문장을 인용해도 후처리의 형태 표현 목록에 `알루미늄캔`이 없어서 `input_form_unproven`으로 떨어졌다. `음료캔·폐캔` 외에 `알루미늄캔·알루미늄 캔`도 같은 형태로 인식한다.

- 재질 검사·정확한 인용 검사·반입 금지 문맥 검사는 유지한다.
- 철제 캔, 알루미늄 스크랩 설명만 있는 경우, 알루미늄캔 반입 금지 문장은 잘못 통과하지 않는다.
- `dispatch_approved=false`를 유지한다. 공개 공정 근거 확인과 실제 물량 수락은 다르다.

검증: route 550개 통과, 72개 환경 의존 검사 생략, 24개 하위 검사 통과. 5개 회귀 사례 추가. 실제 웹 프록시→서버→Azure 재검토에서 해당 업체를 포함한 캔 3후보의 근거 확인 응답을 받았다.

수도권 자료를 포함한 통합 검증은 첫 공정 7조합·실제 산출물 가정의 후속 공정 2조합, 67회 후보 검토다. 신규 19연결 중 근거 확인 7·추가 자료 필요 12이며, 부족한 것을 확인된 것으로 강제하지 않았다. 합성 테스트이며 실배송은 아니다.
