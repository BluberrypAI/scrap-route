# 회사 취급 소재 기준의 문의 후보

2026-11-20 사용자 지시. 기존 사업장별 공정 입증 기준을 후보 탐색 목적에 맞게 낮췄다.

## 바뀐 판단

기존: 정확한 사업장에서 그 소재의 제조·가공을 설명하는 자료와 공정 동사가 있어야 matched. 회사 전체 자료/제품 판매 목록/사업장 역할 추정은 제외됐다.

현재: 서버의 처리업체 카탈로그에 연결된 **회사 자료에 해당 소재 취급·제품이 명시**돼 있으면 문의 후보다. PE/PET 목록, 회사 전체 자료·생산품·제품 판매 목록을 사용할 수 있다. 인용문에 공정 동사가 없어도 되고 `site_role_hypothesis`만으로 탈락시키지 않는다. 기존 `process_match=matched` 필드는 회사·소재 관련 문의 후보라는 뜻으로 사용하며 개별 공정/설비 입증이나 반입 승인을 뜻하지 않는다. API 필드·타입 변경 없음.

동일 후보에 제공된 공개 자료를 사용하고 실제 summary의 인용과 소재 일치를 검증한다. PE/PET 같은 소재 혼동, 명시 취급 제외, 원문에 없는 인용·출처 없음, 모델 미완료와 사진·설명 모순은 유지한다. 공급자 수락·QR 절차는 서버의 기존 흐름을 따른다. 물량 규격·허가·성적서 증빙 질문은 추가하지 않는다.

## 검증

- `pytest`: **602 passed, 72 skipped, 24 subtests passed**. Ruff check/format 통과. 생략 검사는 외부 환경이 필요한 기존 검사이며 이번 Azure 호출과 구분한다.
- 회사 소재 목록/판매 목록/사업장 범위 미확인, PP·PE·PET·알루미늄 후보 포함 및 소재 불일치·부정문·취급 제외·허구 인용 차단 검사.
- 실제 Azure: 과거 제외된 BGF 화성 PE 후보를 회사 자료의 r-PE 제품 표기로 matched, 질문0개·공개1/물량1호출·총 약25.3초. 도로14.112km. 브라우저의 후보 카드/지도/요청 버튼 확인.
- 코드 바이트·지침을 포함하는 기존 review-config 서명이 바뀌므로 이전 부정 공용 캐시는 새 검토에서 재사용하지 않는다. 기존 완료 결과를 소급 승인하지 않는다. 이미 열린 과거 검토는 다시 검토해야 새 기준을 적용한다.

실호출은 별도의 합성 PE 펠릿 로트가 B 처리 후 상태에서 시작한 **후보 기준 시험**이다. 새 문진·A→B QR·실물 처리까지 수행한 E2E를 뜻하지 않는다. 사업장별 설비가 확인됐다고 데이터의 basis를 승격하지 않았으며 실제 업체 연락·운영 배포는 하지 않았다. 서버 #62와 웹 #68의 거리 순위/표시 변경과 함께 적용한다. route를 먼저 적용한다.
