# 11월 18일 경로 엔진 통합 검증

최신 develop과 팀원 PR #23을 로컬 통합했다. #23의 KG 탐색기는 별도 로컬 개발 도구이며, 현재 제품의 PostgreSQL 후보 조회·사진/상태 검토 API에 새로 연결하지 않았다. 기존 처리 경로를 KG로 되돌리는 변경은 없다.

## 이번 역할

문진 확정값과 현재 물량을 서버에서 받아 후보별 공개 근거·현재 형태·상태·사진(첨부한 경우)을 Azure로 검토한다. 이 검토는 실제 업체의 수락과 다르며, 거래·QR·산출물·완료 기록은 scrap-server가 관리한다.

현재 최종 통합의 코드 변경은 서버의 사진 우회 차단·주소/도로 조회, 웹의 입력 순서·완료·지도 표시다. route의 기존 실행 API와 모델 프롬프트는 이번에 새로 바꾸지 않았다.

## 검사

- pytest: **579 passed, 72 skipped, 24 subtests passed**
- Ruff 검사·포맷: 통과
- 선택적으로 생략한 DB/외부 서비스 검사까지 통과했다고 해석하지 않는다.
- 전체 웹·Azure 실호출 검증 범위는 scrap-infra의 `docs/final-integration-20261118.md` 참조.

이 통합 PR에는 아직 develop에 미병합인 팀원 #23의 커밋이 포함된다. #23을 먼저 병합하면 공통 커밋은 자동으로 PR 차이에서 빠진다. KG 개발 도구의 운영 노출·Neo4j 실연결 검증은 이번 서비스 E2E 범위가 아니다.
